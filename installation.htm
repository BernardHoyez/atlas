Installer une application PWA

Une PWA est une application web qui peut être installée sur votre téléphone, votre tablette ou votre ordinateur.

Qu'est-ce qu'une PWA ?

Une PWA (Progressive Web App) est un site Internet conçu pour fonctionner comme une véritable application. Il n'est généralement pas nécessaire de passer par le Play Store ou l'App Store.

Une fois installée, son icône apparaît sur l'écran d'accueil ou dans la liste des applications. Il suffit ensuite de toucher ou de cliquer sur cette icône pour la lancer.

À savoir : la procédure varie légèrement selon l'appareil et le navigateur utilisé.

📱 Android

La méthode la plus simple consiste à utiliser Google Chrome.

  1. Ouvrez la page de l'application avec Chrome.
  2. Attendez quelques secondes. Si l'application est installable, Chrome peut afficher un bouton ou un message proposant « Installer l'application ».
  3. Appuyez sur Installer.
  4. Si aucune proposition n'apparaît, ouvrez le menu ⋮ de Chrome.
  5. Choisissez Installer l'application ou, selon la version d'Android, Ajouter à l'écran d'accueil.
  6. Confirmez l'installation.
Conseil : une fois installée, l'application possède généralement sa propre icône dans la liste des applications.

🍎 iPhone et iPad

Sur iPhone et iPad, utilisez de préférence Safari.

  1. Ouvrez la page de la PWA dans Safari.
  2. Appuyez sur le bouton Partager □↑.
  3. Faites défiler le menu et choisissez « Ajouter à l'écran d'accueil ».
  4. Modifiez éventuellement le nom de l'application.
  5. Appuyez sur Ajouter.

Une nouvelle icône apparaît alors sur l'écran d'accueil. Touchez cette icône pour lancer l'application.

Important : sur iPhone et iPad, l'installation d'une PWA se fait directement depuis Safari. Si vous utilisez un autre navigateur, l'option peut ne pas être proposée de la même manière.

🪟 Windows

Sur Windows 10 ou Windows 11, les navigateurs Microsoft Edge et Google Chrome permettent généralement d'installer une PWA.

  1. Ouvrez la page de l'application dans Edge ou Chrome.
  2. Recherchez l'icône Installer dans la barre d'adresse. Elle peut apparaître sous la forme d'un petit écran avec un symbole « + ».
  3. Cliquez sur cette icône puis sur Installer.
  4. Si l'icône n'apparaît pas, ouvrez le menu du navigateur ⋮.
  5. Cherchez Installer cette application ou une option équivalente.

L'application peut ensuite apparaître dans le menu Démarrer de Windows et éventuellement être ajoutée à la barre des tâches.

💻 Mac

Sur un Mac, les PWA peuvent être installées notamment avec Google Chrome ou Microsoft Edge.

  1. Ouvrez la page de l'application dans Chrome ou Edge.
  2. Cherchez le bouton Installer dans la barre d'adresse.
  3. Cliquez dessus puis confirmez l'installation.
  4. Si le bouton n'est pas visible, ouvrez le menu ⋮ et recherchez l'option d'installation.

L'application pourra ensuite être lancée comme une application classique depuis le Mac.

💻 Chromebook

Sur Chromebook, la procédure est très proche de celle d'Android et de Chrome sur ordinateur.

  1. Ouvrez l'application avec Google Chrome.
  2. Cliquez sur le bouton Installer dans la barre d'adresse lorsqu'il est proposé.
  3. Confirmez l'installation.

L'application apparaît ensuite dans le lanceur d'applications du Chromebook.

🌐 Si aucun bouton « Installer » n'apparaît

Ce n'est pas forcément un problème. Certains navigateurs ne proposent pas automatiquement l'installation.

  1. Ouvrez le menu du navigateur (souvent représenté par ⋮ ou ☰).
  2. Recherchez une option appelée Installer l'application, Installer ou Ajouter à l'écran d'accueil.
  3. Si cette option n'existe pas, vérifiez que vous utilisez un navigateur compatible avec les PWA.
Astuce : sur smartphone, essayez en priorité Chrome sur Android et Safari sur iPhone/iPad.

🔄 Mettre à jour une PWA

Une PWA se met généralement à jour automatiquement lorsque son développeur publie une nouvelle version.

Si vous constatez qu'une ancienne version est toujours affichée, fermez complètement l'application puis relancez-la. Une actualisation de la page peut également être nécessaire.

🗑️ Désinstaller une PWA

Une PWA se désinstalle comme une application classique.

  • Android : appui prolongé sur l'icône puis Désinstaller.
  • iPhone/iPad : appui prolongé sur l'icône puis Supprimer l'app.
  • Windows : utilisez le menu Démarrer ou les paramètres des applications.
  • Mac : utilisez la méthode proposée par le navigateur ayant installé la PWA.

En résumé

Android : Chrome → menu ⋮ → Installer.

iPhone / iPad : Safari → Partager □↑ → Ajouter à l'écran d'accueil.

Windows : Chrome ou Edge → Installer.

Mac : Chrome ou Edge → Installer.

Chromebook : Chrome → Installer.

Une fois installée : vous n'avez plus besoin de rechercher l'adresse Internet de l'application. Utilisez simplement son icône comme pour n'importe quelle autre application.
